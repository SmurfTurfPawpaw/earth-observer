# Earth Observer data policy

Reviewed 11 October 2026. This is the deployment source policy, with evidence and conditions, rather than a certification of every possible use. The source code remains MIT; the copyright notice and third-party attribution stay with the copy. The [upstream source inventory](https://github.com/bilawalsidhu/gods-eye-view/blob/591f299d11f38a612629a274463196d57ae3862e/DATA_SOURCES.md) records original provenance, including providers that this deployment excludes. This document and `src/core/provider-policy.json` describe the smaller deployment policy.

This records source permissions and admission conditions. The actual shipped layers are listed in `src/core/catalog.js`; a permitted source listed here does not imply that every upstream feature using it remains in this build.

`allowed` means the identified data and public service permit the intended interactive display, subject to the listed conditions. `configured` means the integration can remain in the source but must stay inactive until the deployer supplies the required account, credential, agreement or service. `excluded` means no request, fallback, bundled dataset or public UI choice should activate that provider in this deployment. A working public URL is insufficient evidence of permission.

## Transit and bikeshare

Allowed transit feed IDs are `mbta`, `capmetro-austin`, `hsl-helsinki`, `ovapi-nl` and `entur-norway`.

- [MBTA/MassDOT licence](https://www.mass.gov/doc/developers-license-agreement-11132009/download) permits use, reproduction and redistribution; credit the agency as text, with no unauthorized agency logo.
- [CapMetro licence](https://www.capmetro.org/developertools) covers the hosted realtime vehicle data; it prohibits use of its trademarks/copyrighted branding with the data.
- [HSL open data](https://www.hsl.fi/en/hsl/open-data) is CC BY 4.0; attribution includes the data delivery time.
- [OVapi README](https://gtfs.ovapi.nl/README) permits use and requires identifying User-Agent, gzip, and conditional requests when polling faster than once/minute.
- [Entur terms](https://developer.entur.no/terms-of-service) permit commercial reuse under NLOD and require a real application `ET-Client-Name`, source/licence attribution and a modification notice.

`translink-seq` is configured-only: its [CC BY feed](https://translink.com.au/about-translink/open-data) is permitted, but its [terms](https://translink.com.au/about-translink/open-data/terms-and-conditions) require current contact details and the realtime feed must be used alongside schedules. `metrotransit-msp` is excluded: the public-domain assertion for a companion schedule dataset does not establish rights for its separate realtime feed.

Approved bikeshare IDs are `nyc-citibike`, `chicago-divvy` and `dc-capital-bikeshare`, only as an integrated station-availability map, with [Citi Bike](https://citibikenyc.com/data-sharing-policy), [Divvy](https://divvybikes.com/data-license-agreement) and [Capital Bikeshare](https://capitalbikeshare.com/data-license-agreement) operator terms. These allow product/service integration but prohibit standalone dataset hosting, resale/export, customer correlation, claimed affiliation and unauthorized logos/trade names. Generic raw dataset exports/proxies are outside this approval. Other upstream GBFS systems remain excluded until their operator terms are recorded. Their fetched `system_information.json` records did not specify licences, and they use GBFS 1.1/2.3; the newer GBFS 3.0 default must not be applied retrospectively.

## Integrations requiring deployer configuration

The hosted baseline retains the configured live FIRMS API and the gated CCTV providers described above. Google Maps tiles/Places/Geocoding, Cesium ion assets, TomTom traffic, Mapillary, Open-Meteo, Esri imagery and routing integrations are removed from this build. The references below explain the conditions for any later reintroduction; setting a key alone does not restore those features or establish blanket rights. A later integration must maintain provider attribution, budget controls and restrictions on extraction, screenshots, caching and other uses.

- [Google Map Tiles policies](https://developers.google.com/maps/documentation/tile/policies): current EEA billing-address terms apply to the Brussels deployer where relevant. The upstream screenshot-based voice feature and extracted Google geometry/heights are removed. Any later Google integration must respect its prohibitions on machine interpretation and geodata extraction.
- [Cesium ion terms](https://cesium.com/legal/terms-of-service/): CesiumJS's open-source licence does not license ion-hosted assets or confer plan eligibility.
- [TomTom developer terms](https://docs.tomtom.com/legal/terms-and-conditions): use a suitable account/key and contract, preserve traffic credit, and respect the account quota and permitted caching.
- [Mapillary terms](https://www.mapillary.com/terms): imagery and API use have separate conditions. Configure a client token only after accepting the current terms; preserve the imagery attribution/share-alike conditions where applicable.
- [Open-Meteo terms](https://open-meteo.com/en/terms): the free service is noncommercial even though its data is CC BY 4.0. Commercial/promotional deployment needs the paid endpoint/key, or a replacement/self-hosted service. Do not retain the free endpoint as an automatic fallback.
- [Esri service terms](https://www.esri.com/en-us/legal/terms/web-site-service): the upstream keyless World Imagery endpoint is excluded by default. Restore a suitable Esri service only under the deployer's applicable commercial agreement and provider attribution.
- Routing can use a separately configured self-hosted OSRM service and ODbL routing data. The default [FOSSGIS service](https://routing.openstreetmap.de/about.html) / [commercial-use restrictions](https://www.fossgis.de/gesellschaft/fossgis-e-v/nutzungsbedingungen/) are not approved as a general production commercial service.

## Removed / inactive sources and assets

| Source | Reason and affected paths |
| --- | --- |
| OpenSky | [Operational live API use requires a written licence](https://opensky-network.org/about/terms-of-use), including nonprofit live services. Remove `server/providers/aircraft/opensky.js` from active flight routing and all automatic fallbacks. |
| adsbdb | The service has no general published licence; its route source expressly restricts copying/publication without permission. Remove `server/providers/aircraft/enrichment.js` from active API routing and browser enrichment requests. |
| AISStream | [Service documentation](https://aisstream.io/) permits server proxying but does not publish a sufficiently specific redistribution/data licence for this policy. Exclude live vessel requests until written reuse terms are recorded. |
| Google News RSS | [Google News terms](https://www.google.com/intl/en_us/terms_google_news.html) restrict use to personal noncommercial activity. Remove the RSS path and use GDELT metadata only. |
| TeleGeography cable data | CC BY-NC-SA 3.0. Exclude `src/data/local_data/telegeography_submarine_cables/` and the cable layer until separately licensed. |
| Bhote Koshi imagery and derived path | CC BY-NC 4.0. Exclude `public/events/bhote-koshi-2026/`, `src/data/bhoteKoshiFloodPath.js`, and the Nepal event scene's registrations/imports. Deleting the image folder alone leaves restricted coordinates compiled into the build. |
| Precomputed Google-derived CCTV heights | Exclude `src/data/local_data/cctv_ground_heights/` and serve independently licensed terrain-derived placement instead. Its provenance describes extraction from Google Photorealistic 3D Tiles, whose current policies prohibit geodata extraction. |
| Animated road traffic and routing | Removed from the hosted layer catalog. The upstream road-traffic animation does not represent observed vehicle positions. TomTom live traffic, the public FOSSGIS routing service and the local routing integration are not mounted in this build. OSM road geometry remains permitted in the basemap; that does not clear unrelated traffic services. |
| Aircraft and ship models | The model feature and its assets are removed. Any later reuse must restore the original creator, source, licence and modification notices from the [upstream model provenance](https://github.com/bilawalsidhu/gods-eye-view/blob/591f299d11f38a612629a274463196d57ae3862e/public/models/README.md). |
| Local SDR/receiver services | Local-receiver plumbing is not a publicly hosted upstream data service. Exclude server routes that read private/local decoder feeds from the public deployment. |

Public-hosting checks must verify both sides: excluded sources cannot be enabled by saved URL state or browser controls, and their server routes, custom configurations and fallback paths cannot fetch them. Keep attribution visible while data is displayed. Refresh this policy when a provider, endpoint, dataset, licence or use changes.

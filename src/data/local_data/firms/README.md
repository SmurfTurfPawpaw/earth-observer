# Archived NASA FIRMS sample

`snapshot.json` contains 45 real NOAA-20 VIIRS detections with acquisition
dates of 2026-07-16, converted from the upstream project's recorded
`src/data/fixtures/firms-viirs-noaa20-sample.csv`. Their original capture time
is unavailable; the displayed date means acquisition date.

This is a historical sample, not current conditions or comprehensive global
coverage. The keyless API explicitly identifies it as archived and stale.
Configuring `FIRMS_MAP_KEY` selects the current NASA FIRMS feed instead.

Source and attribution: NASA FIRMS / NOAA-20 VIIRS,
https://firms.modaps.eosdis.nasa.gov/ .
